Nupta — Learning Intelligence

Gemini is free and already set up — you only need a key here to use Claude or GPT models. Add one and those options become selectable in every tab's model dropdown.

Where your keys go

  • No server. Nupta is entirely on-device — a key goes only to its own provider.
  • Never in a web page. Keys are read only inside the extension's background worker, never by the widget on your lecture page, so no site you visit can reach them.
  • Stored on this device in extension storage, which other extensions can't read. It is not encrypted on disk — anyone with access to your computer could read it, the same as a saved browser password. If a key is ever exposed, revoke it at the provider using the link above.
